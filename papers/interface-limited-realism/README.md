# Interface-Limited Realism — formal monograph (LaTeX)

`interface-limited-realism.tex` — a self-contained formal monograph on
observer-constrained knowledge: observation as a non-expansive interface
operation, objective knowledge as the interface invariant
`I = ∩_i Fix(Φ_i)` (a von Neumann algebra under a faithful invariant state),
a constructed complete semantic metric, a strictly contractive anchored
stabilizer (`κ = 1−δ`), the compositional/functorial structure, a scope
(demarcation) theorem, and an empirical falsification protocol. Every
non-trivial claim is status-tagged; standard results are labelled as such.

## Build

```bash
pdflatex interface-limited-realism.tex
pdflatex interface-limited-realism.tex   # second pass for TOC/refs
```
Compiles cleanly with TeX Live (report class, amsthm; no exotic packages).
25 pages.
